# API ledger: Laravel `/api` routes vs Rust

Generated from `php artisan route:list --path=api --json`. One row per method.
"native" means the Rust gateway serves the route when its group is in `RUST_NATIVE_ROUTES`; "proxied" means
Laravel still answers. "Parity" is the state from `scripts/parity/compare.py`:
`partial` = auth and errors match, payload shape not yet identical; `full` = every role matches.

The Rust-only `GET /api/v1/dashboard` (SPA aggregate) is not a Laravel route.
